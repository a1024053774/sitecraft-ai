## Resolution

2026-10-07 负责人决定：

- **冻结验收工具链**：T-117（已关）、T-119（本次以「冻结、不继续」关闭）已写入主线的代码保留不回滚，不再继续这条链；T-119 未提交的半成品存在 `git stash`（`frozen-2026-10-07`），不合入。AGENTS.md 删掉这两天新增的三段截图 / 浏览器归属 / 逐图核对细则，改为一句：验收工具本身的完善属于优先级 3，工具出问题只开一张票如实记录，不连开基础设施票、不为它挡住页面质量工作，不做哈希 / 字节 / 像素比对，不拷贝源码 / 依赖 / 构建目录当证据。
- **T-110 回到 T-104 原口径**：两种二选一盲猜（混排每轮 3 家公司、生成页 + 2 张真实工业官网截图，猜中 ≤ 50%；同样子换公司，判「同一模板」≤ 50%），不再加码遮挡和多实例矩阵。
- **T-118 只修根因**：产能事实「资料给了数量、单位、周期就要对应保留」在现有商业条款核对里修好，补行为测试即可，不扩成独立证据系统。
- **清理**：删除 21 个已合并的 worktree 和 artifacts 里的旧截图、核对副产品（Code 文件夹 69 GB → 22 GB），只保留各票 `.md` 报告和最近一次主线复验。
