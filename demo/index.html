在本地用自己的模型接口运行

上面每一步都是工作台的真实界面，内容来自模拟资料「禾巷小馆」的一次真实生成和两轮真实批注修改。这个演示是静态页面，不调用模型。

获取源码

github.com/a1024053774/sitecraft-ai

本地运行

需要 Node 22 和一个 Chrome（推荐 chrome-headless-shell，提交检查用它在三档宽度下核对页面）。

git clone https://github.com/a1024053774/sitecraft-ai.git
cd sitecraft-ai
npm ci
CHROME_PATH=/path/to/chrome-headless-shell npm run dev

打开 http://localhost:3000/settings，在「模型接口」里填写 API 地址、key 和模型名（目前只保证 DeepSeek 兼容接口可用）。key 只保存在你的浏览器里。之后从「新建站点」发来公司资料，就会走一遍上面的流程。更多说明见仓库 README。
