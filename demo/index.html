    在本地用自己的模型接口运行

    上面每一步都是工作台的真实界面，内容来自模拟资料「禾巷小馆」的一次真实生成和两轮真实批注修改。这个演示是静态页面，不调用模型。

    获取源码

    github.com/a1024053774/sitecraft-ai

    git clone https://github.com/a1024053774/sitecraft-ai.git
cd sitecraft-ai

    本地运行

    两种方式任选其一。

    Docker Compose

    需要 Docker 和 Docker Compose。它同时启动建站服务和 PostgreSQL，镜像里自带提交检查用的 Chrome，不需要另装 Node。在源码目录新建 .env，只写数据库密码（字母和数字）与端口：

    POSTGRES_PASSWORD=换成一串足够长的随机字母数字
SITECRAFT_PORT=3100
    docker compose up -d --build

    启动后打开 http://localhost:3100。站点和版本存在 Docker 卷里，停止或重启都不会丢。

    Node 开发模式

    需要 Node 22 和一个 Chrome（推荐 chrome-headless-shell，提交检查用它在三档宽度下核对页面）。

    npm ci
CHROME_PATH=/path/to/chrome-headless-shell npm run dev

    启动后打开 http://localhost:3000。

    填写模型接口

    在工作台的设置里打开「模型接口」，填写 API 地址、key 和模型名（目前只保证 DeepSeek 兼容接口可用）。key 只保存在你的浏览器里。之后从「新建站点」发来公司资料，就会走一遍上面的流程；生成中途断开时，资料会保留，已确认的大纲点一下就能接着生成。更多说明见仓库 README。
