# 页面骨架版式卡

这些卡片提供内容顺序与空间关系的参考，不是模板、区块白名单或行业映射。先看资料里最厚的内容、访客的查找任务和授权图片，再选一个起点；两种风格都能采用任意骨架。可以调整、省略或另创结构，不为凑卡片补事实。
每次规划的卡片展示顺序随机，不代表推荐顺位。先按资料比较至少两张；模型输出顶层 skeletonId 和 skeletonReason，不嵌套骨架对象。选卡用下面的 id，另创用 custom；理由同时点出主选的资料依据、首屏与节奏，以及次合适那张为何这次不选。系统保存选择和本次顺序；summary 用客户能懂的话概述，不写内部 id。内页按自己的任务展开。
写页时把选择落实到首屏、产品入口和区块顺序，不能只改骨架名称；结构理由只在大纲里，不进入企业页面。尺寸、颜色和字阶由用户风格与滑杆决定。所有内容仍走核心规范与提交入口。
序列只安排资料支持的内容；未提供的新闻、案例、认证、下载、搜索、商城与服务承诺不出现。链接只指向实际页面或锚点，询盘采用系统表单。首屏挑选入口或关键事实，完整参数放在所属产品处，避免重复整份参数。

## product-atlas 产品族入口
适合：至少三个差别明显的产品系列，且资料以分类目录为主、采购首先需要浏览并比较系列。只有两个系列，或资料重点是加工承接、成交路径、打样流程时，这张不适用，应选其他起点或 custom；不能因为有参数就忽略这些条件。
首屏：短公司定位下直接展开可点击的产品族目录，主次按资料厚度分配；产品入口承担主视觉，不另放右侧四格参数。
序列：产品族入口 → 一个重点系列的图文简介 → 其余系列的紧凑索引 → 有依据的加工或检测 → 联系；首页给区别，完整规格到产品页。
图少/无图：有图的系列获得较大位置；其余用名称、用途与一项区别组成文字目录，无图时用开敞的排版索引，不画空图框。手机目录顺序不变。

## flagship-focus 单品展台
适合：一个主打产品或系列的资料显著更厚，产品外形、用途或关键范围能表达业务。
首屏：通栏产品名与一句用途，产品图作为下一层的大幅主体，说明贴近图的边缘；无图时关键范围成为中轴主视觉。
序列：主打产品 → 用途与适用边界 → 规格细节 → 配套产品的短目录 → 制造/质量证据 → 询盘；从整体认识逐步进入细节。
图少/无图：唯一产品图集中在展台，不在后文重复；无图用一组有来源的范围与短说明，不把所有产品强行变成主打。窄屏先看名称再看主体。

## application-paths 按工况进入
适合：资料明确给出多个用途或工况及对应产品，访客知道使用场景但未选型号。
首屏：业务定位与工况入口上下展开，可用横向场景带或一主多辅的分区；不以企业能力数字开场。
序列：工况选择 → 各工况的要求与对应产品 → 共有能力 → 有依据的质量信息 → 带工况提示的询盘；规格跟在对应产品后。
图少/无图：有授权场景图才用场景画面；否则用工况名称、约束与产品链接形成文字路径。没有明确对应关系就选别的卡，不推断产品适用性。

## workshop-story 现场叙事
适合：有可用于该公司的现场照片和具体工序/设备资料，访客要判断生产现场与加工能力。
首屏：整宽现场画面配短业务标题，下一块用窄正文与宽设备内容拉开比例；照片先交代环境，文字再交代能力。
序列：现场 → 具体工序与设备 → 对应产出/产品 → 检测动作及状态 → 联系；长短段、照片与清单交替，不连排等大图文块。
图少/无图：一张真实现场图只用一次；行业配图不能称本厂实拍。没有可对应的现场图时改成工序叙事，以工序名和设备清单组织，不假造车间或空占位。

## capability-led 加工范围先行
适合：承接来图加工或定制，材料、工艺、尺寸/精度边界比标准产品目录更完整。
首屏：加工任务与范围组成通栏说明，下面紧接一条有来源的工艺目录；主行动通向加工范围，询盘在后段承接。
序列：加工范围 → 材料/工艺分组 → 设备与检测的不同尺度内容区 → 可制作的产品例项 → 订购边界 → 联系；规格只在需要核对处成表。
图少/无图：设备图贴在对应设备旁，其他部分以分组清单和短说明为主；无图让范围占宽、说明收窄，靠层级而非一排大数字建立重点。

## two-businesses 两条业务路径
适合：资料确有两条不同采购路径，如标准件与定制、产品与加工服务；区别和各自承接条件清楚。同一成交路径里的两个标准产品系列不算两条业务，仅规格或接口不同不适用这张，应选其他起点或 custom。
首屏：公司定位下一次给出两个真实入口，可用宽窄分区或上下相接的两块；按业务权重排，不把两条都做成四格参数。
序列：两条路径 → 主业务的完整介绍 → 次业务的短介绍 → 共用设备/质量 → 各自成交条件 → 合并联系；没有证据的共用条件不合并。
图少/无图：有图的一路先用图建立重点，另一路用文字；无图靠名称、用途和条件分开，手机先主后次。不能把加工方式虚构为第三种商品。

## process-journey 沿流程认识业务
适合：资料给了明确顺序的打样、加工或质检动作，采购需要知道产品怎样形成或怎样核验。
首屏：短标题与实际起点/终点，流程作为下方通栏主体；步骤使用原生有序列表或标准计数器，不手写数字。
序列：实际流程 → 某个关键动作的较宽说明/照片 → 相关产品与规格 → 交付条件 → 联系；关键阶段详写，其余收紧，避免每步等大。
图少/无图：仅有一图就贴在对应阶段；无图用纵向步骤、缩进与留白体现先后。流程不足或资料未给顺序时选其他结构，不补行业惯例。

## compact-profile 短页名片
适合：产品少、公司资料薄，只有业务、几项能力和联系方式，访客主要是确认承接范围。
首屏：公司名、具体业务短句与一个有效入口放在紧凑的单栏，不撑满屏、不加统计或参数面板。
序列：业务定位 → 有内容的产品/能力，按详略占不同位置 → 真实联系方式与短询盘区；内页可以短，不凑沿革、证书或 FAQ。
图少/无图：有一图就与最相关条目同排；无图直接做文字页，用清楚的字阶和段落宽度组织。手机保持同一阅读顺序，减少无内容的大留白。
