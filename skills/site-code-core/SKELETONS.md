# 页面骨架版式卡

这些卡片提供内容组织与空间重心的起点，不是模板、区块白名单或行业映射。所选风格、资料重心与骨架共同决定首屏形态、栏数比例及区块取舍与先后顺序；可以调整、省略或以 custom 另创结构，custom 与选卡同权，不为凑卡片补事实。
每次规划的卡片展示顺序随机，不代表推荐顺位。先按资料比较至少两张；模型输出顶层 skeletonId 和 skeletonReason，不嵌套骨架对象。选卡用下面的 id，另创用 custom；理由同时点出主选的资料依据、首屏与节奏，以及次合适那张为何这次不选。系统保存选择和本次顺序；summary 用客户能懂的话概述，不写内部 id。内页按自己的任务展开。
写页时落实已选定的风格整页构图、首屏重心和区块顺序，不能只改骨架名称；结构理由只在大纲里，不进入企业页面。所有内容仍走核心规范与提交入口。
序列只安排资料支持的内容；未提供的新闻、案例、认证、下载、搜索、商城与服务承诺不出现。链接只指向实际页面或锚点，联系只在用户资料或要求中明确提出时才追加；以下序列不默认带这些内容。多页站点的首页聚焦最能代表这家机构的 3–5 个核心区块，首屏可按所选风格构图与资料实据直接展开核心规格/价目对照、到访指引、主流程或主张；次要沿革、动态与问答可归入对应内页。

## product-atlas 分类目录入口
适合：两个及以上差别明显的产品或服务系列，访客进站需要横向浏览并比较系列特征、规格或收费条件。
首屏：短机构定位下直接展开分类规格对照或主次不等宽目录，主次按资料厚度分配；业务目录本身承担主视觉。
序列：分类规格对照或主次入口 → 重点系列的图文或边界说明 → 选型与合作前提；完整细目按页面职责放入对应内页。
图少/无图：有图的系列获得较大位置；其余用名称、用途与关键指标组成文字或表格目录，无图时用清楚的字阶与栏宽组织，不画空图框。手机目录顺序不变。

## flagship-focus 主打展台
适合：一个主打产品或服务的资料显著更厚，外形、用途或关键范围能表达业务。
首屏：通栏主打名称与一句用途，对应图片作为下一层的大幅主体，说明贴近图的边缘；无图时关键范围成为中轴主视觉。
序列：主打内容 → 用途与适用边界 → 具体细节 → 配套内容的短目录 → 有来源的质量证据；从整体认识逐步进入细节。
图少/无图：唯一主图集中在展台，不在后文重复；无图用一组有来源的范围与短说明，不把所有业务强行变成主打。窄屏先看名称再看主体。

## application-paths 按场景进入
适合：资料明确给出多个使用场景、来访对象或时段及对应业务，访客需要先按自身情况对号入座。
首屏：情境导引与各情境的适用前提、对应业务及关键条件同屏展开，可用宽窄分栏或情境账本呈现。
序列：情境分流主区 → 各情境的要求与对应业务细节 → 共有能力或场地说明 → 交易或到访前提。
图少/无图：有授权场景图才用场景画面；否则用场景名称、约束与业务链接形成文字路径。没有明确对应关系就选别的卡，不推断适用性。

## workshop-story 现场叙事
适合：具体作业方式、活动或设施资料突出，访客要了解环境与业务开展方式（有无本机构实拍图均可采用）。
首屏：整宽画面或编辑式开场交代核心作业方式与场地配置；有真实现场图先交代环境，无实拍图则以具体工序与工位说明开场。
序列：作业方式与设施实况 → 真实活动、记录或对应业务 → 质量核验信息及承接边界；长短段、照片与清单交替，不连排等大图文块。
图少/无图：一张真实现场图只用一次；行业配图不能称本店实拍，不假造现场或空占位。

## capability-led 承接范围先行
适合：按具体需求承接业务或定制，能力、方式与限制比标准零售目录更关键。
首屏：承接任务、能力范围与关键接单边界构成首屏重心，直接交代可承接事项与明确限制。
序列：承接范围与边界 → 代表实务记录或能力分组 → 设施与核验的不同尺度内容区 → 合作条件；详细系列参数与次要沿革动态按需归入内页。
图少/无图：设施图贴在对应设施旁，其他部分以分组清单和短说明为主；无图让范围占宽、说明收窄，靠层级建立重点。

## two-businesses 两条业务路径
适合：资料确有两条对象或承接模式不同的业务路径，区别和各自条件清楚。同一路径里的两个系列不算两条业务，仅规格或选项不同时应选其他起点或 custom。
首屏：机构定位下一次给出两个真实入口与各自适用前提，可用宽窄分区或上下相接的两块，按业务权重分配空间。
序列：两条路径 → 主业务的完整介绍 → 次业务的短介绍 → 共用设施/质量 → 各自交易条件；没有证据的共用条件不合并。
图少/无图：有图的一路先用图建立重点，另一路用文字；无图靠名称、用途和条件分开，手机先主后次。不能把服务方式虚构为第三种商品。

## process-journey 沿流程认识业务
适合：资料给了明确顺序的业务动作，访客需要知道过程怎样开展或怎样核验。
首屏：短标题与实际起点/终点，流程阶段作为下方主体展开；步骤使用原生有序列表或标准计数器，不手写数字。
序列：实际流程主干 → 某个关键动作的较宽说明/照片 → 相关业务与细节 → 交付或合作条件；关键阶段详写，其余收紧，避免每步等大。
图少/无图：仅有一图就贴在对应阶段；无图用纵向步骤、缩进与留白体现先后。流程不足或资料未给顺序时选其他结构，不补行业惯例。

## compact-profile 短页名片
适合：业务少、机构资料薄，只有简介和几项能力或规则，访客主要是确认承接范围。
首屏：机构名与具体业务短句放在紧凑的单栏，有真实内容目标时再给入口，不撑满屏、不加统计或参数面板。
序列：业务定位 → 有内容的产品/服务，按详略占不同位置；内页可以短，不凑沿革、证书或 FAQ。
图少/无图：有一图就与最相关条目同排；无图直接做文字页，用清楚的字阶和段落宽度组织。手机保持同一阅读顺序，减少无内容的大留白。
