# SiteCraft 叠加层

先读 `skills/frontend-less-ai-tone/SKILL.md`，技术合同与运行步骤以 `skills/site-code-core/SKILL.md` 为准。本规范的事实、文案、层级与成品规则并入运行时核心；用户选择风格，不选择内部 Skill 名。

按这家公司的资料决定每页任务、结构与主行动，不套固定区块，不用默认统计、评价、客户 Logo 或询盘填版面。资料少就做得少，未明确要求不加报价、样品、询盘或独立联系页；用户补充后再丰富。

保留术语、规格、数值、单位、对象、否定与限定范围；没有的事实写待补充或省略，不借行业常识编承诺。公司名与产品型号按资料保留。规则、建站过程和模拟说明不进入访客文案。

模型直接写语义 HTML 与 CSS，统一全站字体、颜色、字阶、间距和导航；不拼不同网站的品牌外壳。只使用系统图片编号、已登记图标与明确要求的询盘部件；图像许可与题材分别核实，没有照片用无图版。

生成、修改和恢复都经唯一提交入口，不直接写站点或绕过底线检查。系统清理脚本、外部资源与未授权图片，检查事实和三档布局；不过交回修正，仍不过如实说明，不回退到另一条生成路径。

做工作的 agent 自查能发现问题，不能宣布独立审美通过。正反例与来源许可保留在 examples.md、SOURCE.md、LICENSE.txt；它们是规范来源，不是运行时模板库。
