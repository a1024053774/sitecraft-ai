# 正反例

这些例子只说明成品该长什么样、文案怎么写。不要把公司名、规格或认证抄进真实站点，除非用户资料里有。

## 文案

资料：减速机厂，主推硬齿面减速机，要规格表，没有认证和客户名单。

| 位置 | 不要 | 要 |
| --- | --- | --- |
| 首屏标题 | 赋能智造，引领未来 | 硬齿面减速机，按工况选型 |
| 首屏说明 | 我们提供全面、领先、无缝的一站式解决方案 | 按速比、扭矩和安装面给选型表；认证与产能待补充 |
| 主按钮 | 立即体验 / 开启未来 | 获取规格表 |
| 优势卡 | 三张都写「专业、可靠、高效」 | 一张写速比范围，一张写安装面，一张写交期怎么问；没有的写成待补充 |
| 空状态 | 抱歉，暂时无法展示 | 认证文件待补充。有扫描件后可以放到本区 |

Hero 已经说了「按工况选型」，优势区不要再喊一遍同一句。按钮要让人知道点下去会拿到规格表，不是「开始一段体验」。

外贸接头目录同理：标题写介质、压力和接口标准，不要写「全球领先流体解决方案」。没有样品政策就写「样品政策待补充」，不要编「免费寄样 3 个工作日」。

## 样子

| 资料线索 | 选 | 不要 |
| --- | --- | --- |
| 要产品线和询盘，工况图有限 | 工程工业（`screwfast` 当素材） | 为了「更工业」去拼外站橙底工地皮 |
| 分类多、要目录和询盘表 | 蓝白目录（`landwind` 当素材） | 把 Forge 导航接到 Landwind 功能区 |
| 只有一页说清品类 | 灰底短路径（`tailwind-landing` 当素材） | 没有快照却挂「像素风」卡 |
| 用户已点「深色产品」 | `fresh` 当素材，深底功能说明 | 模型再发明一套紫黑渐变 CSS |

同族模块：工业站按 KonsTuck 清单看该有哪些区块（产品、服务、为什么选我们、FAQ、询盘），再用已准入的同族素材组出来。清单里有、当前没有可核素材的，报缺口，不要新建通用商品网格，也不要把 ScrewFast 演示壳留下充数。

Jiro 免费整页气质不像工业，仍可看它的提示词怎么锁 token、怎么写单块。不要把 Copy Prompt 贴进生产。

## 落点

用户说「把主按钮改成索取交期」。

- 要：`set_text` → `hero.cta` →「索取交期」；导航和页脚也必须是这家厂，不能还写 ScrewFast
- 不要：输出一段 `<style>` 或「把按钮改成酸绿」
- 不要：只改标题，留下 Airbnb Logo 墙、`$29` 套餐或 12.8k Reviews
- 联系邮箱找不到落点：报告 `missing`。`missing` 是这次没写成，不是允许演示邮箱留在成品上

提问「现在主按钮写了什么」只 `answer`，不改 revision。
