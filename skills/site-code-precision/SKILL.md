name: site-code-precision
description: 用户风格「精密工程」。
---

冷静、精确，像工程师整理的产品目录。规整网格为主，用细线分组、参数表和字阶承载信息，少用卡片。默认版式变化 5/10、信息密度 6/10；按用户滑杆调整，不丢规格。白或浅冷灰底，深石墨文字，从钴蓝、信号橙、工业绿中选一个适合业务的强调色。全站无动效。

用户给什么资料就做什么网站；只在用户资料或要求中明确提出相应网站功能时才做。不默认增加询盘表单、报价入口、邮箱联系或联系页。已有联系方式可按资料展示，但不据单项邮箱硬套独立联系页；商业条件不等于询盘功能要求。资料少就做得少，用户补充后再丰富。风格只调整现有内容的排法，不补营销流程或页面。
