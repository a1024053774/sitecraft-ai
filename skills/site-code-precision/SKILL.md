name: site-code-precision
description: 用户风格「精密工程」。
---

冷静、精确，像细致整理的业务目录。白或浅冷灰底、深石墨文字，从钴蓝、信号橙、灰绿中选一个适合业务的强调色。以清楚的字阶区分主要业务名称、分组标题与参数正文；可用一处深色规格带与浅底目录形成主次，参数内部再用细线对齐，不把所有小节排成同号标题加横线。无图首屏让已有业务目录或关键范围占宽，与标题上下衔接，不留空的右半屏；有图按用途与说明长度分配栏宽，不强求图文各占一半。资料少时做紧凑短首屏，不用新增数字或重复说明填满。默认版式变化 5/10、信息密度 6/10；按用户滑杆调整网格与疏密，不丢规格。条件只写在资料原文限定的条目旁，导语与分组说明不概括条目条件；不推断资料未明确的关系、地点或适用范围。全站无动效。窄屏时间区间、数量与单位、短标签、型号、邮箱保持完整，不拆开；窄屏长参数串按字段上下排列，表格在窄屏拥挤时改为字段行，字段名写在 HTML 中，保留事实对应关系。只保护语义短串，不整段禁止换行；先放宽内容栏、让标签和值上下排、长邮箱独占一行，不用强制断词、裁切、隐藏或横向滚动凑宽，不新增横向溢出，不删改事实。表格改字段行须整体处理 caption、thead、tbody、tfoot、tr、th、td 的显示与宽度，caption 占满可用宽度；停用 colgroup/col 的列宽约束（仅布局，不隐藏业务文字），保留表题、表头表尾及 th 的 scope 行头关联。若表格在 figure 中，figure 与 figcaption 也检查可用宽度；两列表能正常显示时优先保留原生表格，复杂列关系先按 HTML 显式字段名重组，不只把部分表元素改为 block。

用户给什么资料就做什么网站；不生成表单、提交入口或收件功能。不默认增加报价入口、邮箱联系或联系页。已有联系方式和商业条款按资料展示，但不据单项邮箱硬套独立联系页。资料少就做得少，用户补充后再丰富。风格只调整现有内容的排法，不补营销流程或页面。
