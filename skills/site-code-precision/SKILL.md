description: 用户风格「精密工程」设计配方。
---

冷静、结构严谨的工程参数与分类目录配方，依靠清晰字阶、至少一处深色规格带与紧致直角分格建立层级。页头：顶部分段标尺页头，左侧放方形几何字标与全称，右侧或第二行按参数类别分栏排布导航，禁用 64px 细浅灰线居中漂浮顶栏。字体栈：正文与标题用 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`，型号、速比、公差与年份采用 `ui-monospace, "Cascadia Mono", Consolas, monospace` 并配 `tabular-nums`。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（深铁蓝）主底 #F6F8FA（正文 #1A2128 / 次字 #495460）、次区底 #E9EEF3（正文 #1A2128 / 次字 #444F5B）、深色带 #15202B（正文 #F4F7FA / 次字 #B8C7D6）、强调 #0E4D78（字 #FFFFFF）；变体 B（铸铁信号橙）主底 #FFFFFF（正文 #1E2022 / 次字 #4E5358）、次区底 #F1F2F4（正文 #1E2022 / 次字 #484D52）、深色带 #1D2126（正文 #F7F8F9 / 次字 #C2C8D0）、强调 #963508（字 #FFFFFF）；变体 C（冷灰松石）主底 #F4F7F6（正文 #182321 / 次字 #43524F）、次区底 #E5ECEA（正文 #182321 / 次字 #3F4E4B）、深色带 #102B27（正文 #F2F7F6 / 次字 #B6CFCB）、强调 #0E5A50（字 #FFFFFF）。首屏与分隔：以左宽参数总览加右窄关键边界或通栏深色规格带开场；无图首屏让已有业务目录或关键参数范围占宽，与标题上下衔接，不留空半屏；有图按用途与说明长度分配栏宽；资料少时做紧凑短首屏，不补数字填充。主次之间使用宽色带、等宽前缀与表格对齐，含列表圆点或编号的有底色区块严格使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁做成「白底左上小眉题 + 黑体大标题 + 一段说明 + 单个圆角实心按钮 + 1px 浅灰横线」的通用模板，也不要每块都做等大边框卡或左年份右单句千篇一律横线列表。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
