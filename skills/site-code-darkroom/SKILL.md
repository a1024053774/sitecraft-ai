深炭夜色全域画布，像深夜灯箱与物理暗房中的高对比陈列页：全站深底，靠大面积暗色呼吸感、深浅炭底分区与高亮单一信号色塑造质感，彻底区别于浅底目录。页头：极简深色标尺导航或桌面左侧固定暗色竖轨（顶边无浅灰边线，品牌字标与链接以高亮浅字与细微高亮标对齐，按资料体量与所选整页构图匹配）。字体栈：中文 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` 配数字等宽 `ui-monospace, "Cascadia Mono", Consolas, monospace`，大标题字重紧实、行距约 1.15。配色角色（全站深底，已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（暗炭香槟）主底 #111317（正文 #F1F4F8 / 次字 #B4BCC8）、次区底 #1B1F26（正文 #F1F4F8 / 次字 #B8C0CC）、强调 #E0B86B（字 #111317）；变体 B（深墨青玉）主底 #0F1416（正文 #EFF5F5 / 次字 #AEBEBF）、次区底 #192226（正文 #EFF5F5 / 次字 #B4C4C5）、强调 #6CD4C8（字 #0F1416）；变体 C（夜褐暖铜）主底 #141110（正文 #F6F1ED / 次字 #C5BAB2）、次区底 #211B18（正文 #F6F1ED / 次字 #CBC1B9）、强调 #F0A47A（字 #141110）。首屏与陈列：在没有企业自有实拍图时暗房配方也能独立成立——若仅有授权行业/题材配图，须遵守用途限制、绝不冒充本企业实拍或自有作品，既可将契合题材的授权配图嵌入带微光细框的暗面标本/灯箱格并配如实说明，也可直接用深浅暗底台面、单一信号色刻度、大尺度字标与等宽核心规格/业务展牌撑起首屏；无图首屏通过深浅暗面层次、跨栏亮白大字标题与结构化等宽参数展牌立住视觉，绝不留浅灰空图位；若确有企业自有实拍图则作暗面主舞台陈列；资料少时做凝练暗底短首屏，不造假数据。严格禁用玻璃拟态、发光阴影、紫蓝渐变、透明 opacity 减淡文字；暗色容器及其列表（`ul li::marker`、`ol li::marker`）一律使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁出现白底/米白底正文区块，严禁做成「浅底左上 Kicker + H1 + 短导语 + 单按钮 + 1px 横线」的通用模板。

## 整页构图

规划阶段按资料体裁与核心内容从以下三种整页构图中择一（填入 `compositionId` 与 `compositionReason`），写页阶段按所选构图落实首屏立住方式、区块取舍、先后顺序、栏数与疏密节奏：

- `darkroom-ledger-matrix`（暗台规格账本型，适合多品类规格参数、材质结构或量程对照型资料）：页头用极简深色标尺顶栏；首屏用通栏亮白主标题与一行承接边界定调，同屏紧接全宽多列深炭规格/参数对照表或桌面 3 列参数矩阵直接立住专业凭据；第二区用不等宽主次双栏（约 7:5）并置关键打样/检验工序与代表实务记录；页尾收束为单栏紧凑合作前提与联络方式，次要沿革、问答与近期动态分流至产品或订购内页。
- `darkroom-rail-showcase`（左侧暗轨展柜型，适合手作工坊、器物修缮或按项目深入叙事的资料）：桌面采用左侧固定窄幅暗色导航竖轨配右侧主画布（768px 以下收为顶部深色条）；首屏在右侧主画布以大留白单栏主张配等宽核心工时/收费标牌开场；第二区按主次错落排布桌面 2 列实务项目展柜（主项详写适用条件、次项收紧）；第三区以横向 2–3 格接待时段与送修/来访边界收束，其余细则归入内页。
- `darkroom-stage-dossier`（暗幕主舞台档案型，适合有一项突出主打业务或契合题材配图、强调空间呼吸感的资料）：首屏为中轴或宽幅暗面灯箱主舞台（单幅授权题材图框配如实说明，无图则用跨栏超大字标与核心承接界定撑起首屏）；第二区切换为桌面 3 列紧凑材料/设备/场地要点格；第三区用单栏纵向编号档案条呈现合作或检验步骤；页尾只保留关键边界与邮箱，完整目录与动态放入内页。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
