深炭夜色全域画布，像深夜灯箱与物理暗房中的高对比陈列页：全站深底，靠大面积暗色呼吸感、深浅炭底分区与高亮单一信号色塑造质感，彻底区别于浅底目录。页头：极简深色标尺导航或桌面左侧固定暗色竖轨（顶边无浅灰边线，品牌字标与链接以高亮浅字与细微高亮标对齐，按资料体量二选一）。字体栈：中文 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` 配数字等宽 `ui-monospace, "Cascadia Mono", Consolas, monospace`，大标题字重紧实、行距约 1.15。配色角色（全站深底，已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（暗炭香槟）主底 #111317（正文 #F1F4F8 / 次字 #B4BCC8）、次区底 #1B1F26（正文 #F1F4F8 / 次字 #B8C0CC）、强调 #E0B86B（字 #111317）；变体 B（深墨青玉）主底 #0F1416（正文 #EFF5F5 / 次字 #AEBEBF）、次区底 #192226（正文 #EFF5F5 / 次字 #B4C4C5）、强调 #6CD4C8（字 #0F1416）；变体 C（夜褐暖铜）主底 #141110（正文 #F6F1ED / 次字 #C5BAB2）、次区底 #211B18（正文 #F6F1ED / 次字 #CBC1B9）、强调 #F0A47A（字 #141110）。首屏与陈列：在没有企业自有实拍图时暗房配方也能独立成立——若仅有授权行业/题材配图，须遵守用途限制、绝不冒充本企业实拍或自有作品，既可将契合题材的授权配图嵌入带微光细框的暗面标本/灯箱格并配如实说明，也可直接用深浅暗底台面、单一信号色刻度、大尺度字标与等宽核心规格/业务展牌撑起首屏；无图首屏通过深浅暗面层次、跨栏亮白大字标题与结构化等宽参数展牌立住视觉，绝不留浅灰空图位；若确有企业自有实拍图则作暗面主舞台陈列；资料少时做凝练暗底短首屏，不造假数据。按资料重心改变整页排法与区块顺序（如全宽参数矩阵配横向标本带、左侧竖轨配不等宽项目展柜或分栏目录，工序与沿革按详略选横向阶段带、内嵌业务页或紧凑刻度条），禁止不同公司重复「首屏 + 对称双栏简介 + 左年份沿革 + 右动态」同一套顺序。严格禁用玻璃拟态、发光阴影、紫蓝渐变、透明 opacity 减淡文字；暗色容器及其列表（`ul li::marker`、`ol li::marker`）一律使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁出现白底/米白底正文区块，严禁做成「浅底左上 Kicker + H1 + 短导语 + 单按钮 + 1px 横线」的通用模板。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
