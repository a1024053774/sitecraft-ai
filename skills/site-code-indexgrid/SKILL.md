瑞士国际主义出版网格与工程检索表配方：外露 `1px–2px` 高对比结构格线把版面切分成清晰的矩形单元格，靠粗黑展示大字、外露格线与等宽编号索引建立秩序，零圆角、零柔和卡片。页头：多格表头索引栏（横向外露格线把站名格、核心说明格与导航链接格切分成一张检索表头，可随资料与色板选浅底粗黑实线表头或深底反白表头，禁止 64px 漂浮无框顶栏）。字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` 粗黑字重用于标题，搭配 `ui-monospace, "SFMono-Regular", "Cascadia Mono", Consolas, monospace` 用于目录编号、型号与参数索引。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（印刷朱红）主底 #FFFFFF（正文 #141414 / 次字 #3D3D3D）、次区底 #F0EFEA（正文 #141414 / 次字 #3A3A36）、深底表头 #141414（正文 #FFFFFF / 次字 #C8C8C4）、强调 #B32614（字 #FFFFFF）；变体 B（普鲁士蓝）主底 #F7F7F4（正文 #12151C / 次字 #3B4250）、次区底 #EAECE8（正文 #12151C / 次字 #363D4B）、深底表头 #103A70（正文 #FFFFFF / 次字 #C7D7EE）、强调 #103A70（字 #FFFFFF）；变体 C（信号深绿）主底 #F9F9F6（正文 #121A14 / 次字 #38463B）、次区底 #EAECE6（正文 #121A14 / 次字 #334036）、深底表头 #14472B（正文 #FFFFFF / 次字 #C6DDD0）、强调 #14472B（字 #FFFFFF）。网格与按内容选排法（不规定固定的区块顺序和位置）：首屏按资料形态从多种网格构图中择一——设备规格对比型资料可用上下分层的全宽通栏粗黑主标题格加下方并排多列规格/系列对照矩阵格，多门类服务或作品手记型资料可用顶置横向索引带配三栏服务目录格或左窄目录竖栏配右侧主宣言与手记摘录格，禁止一律做成「左置大标题 + 右侧浮动分类框」单一两栏；无图首屏按所选排法以通栏或分格实有文字与规格填满结构网格，绝不留空半屏；资料少时仅生成实际条目所需的紧凑网格行，不虚构空白单元格充数。步骤/流程按工序详略选横向多格阶段条、双排核对矩阵格，或直接归入产品/服务内页不在首页单列（禁止一律排成「左标题 + 右侧横线分隔编号列表」；横向步骤条的分隔线改用单元格自身的 `border` 或网格 `gap`——若使用原生 `ol` 的 `outside` `::marker`，在 `ol` 设实色底与 `>=36px` `column-gap`、`li` 保持透明底并以前一项 `border-right` 或顶边线分隔为编号留出净空，不要用 `li::before`、`li+li::before` 或 `li::after` 画分隔线）；沿革按节点体量选横向年份刻度格、与简介同排的紧凑纪年格，或置于次要位置（禁止一律排成「左单列年份 + 右侧辅助信息格」）；动态与页脚格数随实际字段伸缩，整页先后顺序服从所选页面骨架与访客首要任务。全站严格 `border-radius:0`、`background-clip:border-box`，列表用 `ul li::marker` / `ol li::marker` outside 标记与 `z-index:auto`。反雷同禁令：严禁去掉外露格线退化为浅灰悬空留白区，严禁套用「左文右框首屏 → 业务 → 左标右列步骤 → 左年份沿革 → 动态 → 四格页脚」的固定模板或「左上 Kicker + H1 + 单按钮 + 下两平分栏」的通用模板。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
