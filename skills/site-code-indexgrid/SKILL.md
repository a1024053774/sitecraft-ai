瑞士国际主义出版网格与工程检索表配方：外露 `1px–2px` 高对比结构实线把整个版面切分成清晰的矩形单元格，靠格线、反白深底表头与等宽数字前缀建立秩序，零圆角、零柔和卡片。页头：多格表头索引栏（横向外露格线把站名格、核心说明格与导航链接格切分成一张表头检索条，禁止 64px 漂浮无框顶栏）。字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` 搭配 `ui-monospace, "SFMono-Regular", "Cascadia Mono", Consolas, monospace` 用于目录编号、型号与参数索引。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（印刷朱红）主底 #FFFFFF（正文 #141414 / 次字 #3D3D3D）、次区底 #F0EFEA（正文 #141414 / 次字 #3A3A36）、深底表头 #141414（正文 #FFFFFF / 次字 #C8C8C4）、强调 #B32614（字 #FFFFFF）；变体 B（普鲁士蓝）主底 #F7F7F4（正文 #12151C / 次字 #3B4250）、次区底 #EAECE8（正文 #12151C / 次字 #363D4B）、深底表头 #103A70（正文 #FFFFFF / 次字 #C7D7EE）、强调 #103A70（字 #FFFFFF）；变体 C（信号深绿）主底 #F9F9F6（正文 #121A14 / 次字 #38463B）、次区底 #EAECE6（正文 #121A14 / 次字 #334036）、深底表头 #14472B（正文 #FFFFFF / 次字 #C6DDD0）、强调 #14472B（字 #FFFFFF）。首屏与网格：首屏采用边框外露的网格单元，一格放跨格大号黑体标题，邻格放目录索引摘要或深底反白入口格；无图首屏用文字与规格单元格填满结构网格，绝不留空半屏；资料少时仅生成实际条目所需的紧凑网格行，不虚构空白单元格充数。全站严格 `border-radius:0`、`background-clip:border-box`，列表用 outside 标记与 `z-index:auto`。反雷同禁令：严禁去掉外露格线退化为浅灰悬空留白区，严禁做成「左上 Kicker + H1 + 单矩形小按钮 + 下方两平分栏」的通用模板。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
