description: 用户风格「邻里日常」，按具体服务、价目与到访信息生成和修改展示站。
---

像这家店自己整理的店内价目与告示：用有分量的系统黑体标题、清楚的正文和柔和的浅色块组织信息。浅米底、深褐字，从业务气质选一处叶绿或砖红作强调；少量转角柔和的色面承载一组相关信息，不把每项都装进等大卡片。不用衬线画册标题、整宽深色舞台、阴影或装饰图案制造气氛。全站无动效。

开场先呈现资料里最能帮助访客选择的一项业务，紧接真实的菜单、课程或服务内容；名称、价格、适用条件与时间放在对应项目旁，能一眼找到。到访信息有来源才做紧凑告示，无图时靠字阶、色面与真实内容形成记忆点，不补照片、插画或店面示意。手机按同一阅读顺序单列；按用户滑杆调整主次与留白，不固定区块、页数或卡片数量。

风格只改变现有资料的排法，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不增加联系、预约、报价或询盘功能。来源：本项目原创风格，沿用项目代码许可。
