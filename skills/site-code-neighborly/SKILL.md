description: 用户风格「邻里日常」，按具体服务、价目与到访信息生成和修改展示站。
---

像这家店自己整理的店内招牌、价目与告示：大号系统黑体业务名称、清楚的项目正文与紧凑告示拉开字阶，名称、价格和适用条件各有主次。浅米底、深褐字，从业务气质选一处叶绿或砖红作强调；柔和的浅色面按内容分组，重点业务色块与开敞价目交替，不把每项装进等大卡片或用横线切满全页。无图首屏将业务招牌与已有项目上下相接，有来源的到访信息才配紧凑告示，不留右侧图位；资料少时用短开场，不加插画或重复内容撑高。有图贴近对应项目，按主体比例收放，不与几行文字硬凑双栏。不用衬线画册标题、整宽深色舞台、阴影或装饰图案制造气氛。条件只写在资料原文限定的条目旁，导语与分组说明不概括条目条件；不推断资料未明确的关系、地点或适用范围。全站无动效。窄屏时间区间、数量与单位、短标签、型号、邮箱保持完整，不拆开；窄屏长参数串按字段上下排列，表格在窄屏拥挤时改为字段行，字段名写在 HTML 中，保留事实对应关系。只保护语义短串，不整段禁止换行；先放宽内容栏、让标签和值上下排、长邮箱独占一行，不用强制断词、裁切、隐藏或横向滚动凑宽，不新增横向溢出，不删改事实。

开场先呈现资料里最能帮助访客选择的一项业务，紧接真实的菜单、课程或服务内容；名称、价格、适用条件与时间放在对应项目旁，能一眼找到。到访信息有来源才做紧凑告示，无图时靠字阶、色面与真实内容形成记忆点，不补照片、插画或店面示意。手机按同一阅读顺序单列；按用户滑杆调整主次与留白，不固定区块、页数或卡片数量。

风格只改变现有资料的排法，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不增加联系、预约、报价功能，不生成表单、提交入口或收件功能。来源：本项目原创风格，沿用项目代码许可。
