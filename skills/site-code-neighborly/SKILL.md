像这家店自己贴在门口与墙上的整洁招牌、价目牌与营业告示：高饱和深色整幅店招、分色块清单与贴邻紧凑告示形成明快对比。页头：全宽整色块「店招」页头（高对比深色招牌条承载宽大店名与直达业务/价目链接，禁用白底单行 64px 细灰边顶栏）。字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`，价格、时段与份数使用 `ui-monospace, Consolas, monospace` 配 `tabular-nums`，不用画册细宋体与装饰花纹。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（市集靛青）主底 #F7F6F1（正文 #222320 / 次字 #4B4E47）、色块 #E5ECE9（正文 #1B2421 / 次字 #414F4B）、招牌 #1F4B43（正文 #F7F6F1 / 次字 #C8DDD8）、强调 #1C5D53（字 #FFFFFF）；变体 B（烘培麦褐）主底 #F9F5EC（正文 #28211A / 次字 #54473A）、色块 #EFE4D0（正文 #28211A / 次字 #4E4135）、招牌 #4A2E1B（正文 #FAF5EC / 次字 #DECBB8）、强调 #7A341A（字 #FFFFFF）；变体 C（果蔬苔绿）主底 #F5F7F2（正文 #1E241B / 次字 #475242）、色块 #E3EBD9（正文 #1E241B / 次字 #3F4A3B）、招牌 #264222（正文 #F5F7F2 / 次字 #C7D9C4）、强调 #2D5E29（字 #FFFFFF）。首屏与价目组织：开场直接把店招名称、核心价目/课程重点与有来源的营业时段紧凑告示并置成面；无图首屏将业务招牌、核心项目与到访信息紧凑告示紧密衔接，不留右侧空图位；资料少时用短开场收紧，不加插画撑高；有图贴近对应条目，不把几行短字硬凑大双栏。重点色面与开敞清单交替，不把每项装进等大圆角卡片，含列表圆点或编号的有底色区块严格使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁做成「白底左上 Kicker + 黑体标题 + 单个铁锈红按钮 + 1px 横线 + 下二平分栏」的通用模板。

首页开场与推荐区块必须把精选菜品、课程或服务条目旁对应的资料价格、时段与关键适用条件直接写出（不得延后到二级页再补）；菜单或价目存在共用包含或加配边界（如米饭、包材或服务不包含项）时，在菜单或价目页用清晰汇总表或结构化提示区集中呈现。开场先呈现资料里最能帮助访客选择的一项业务，紧接真实的菜单、课程或服务内容；名称、价格、适用条件与时间放在对应项目旁，能一眼找到。到访信息有来源才做紧凑告示，无图时靠字阶、色面与真实内容形成记忆点，不补照片、插画或店面示意。

风格只改变现有资料的排法，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不增加联系、预约、报价功能，不生成表单、提交入口或收件功能。
