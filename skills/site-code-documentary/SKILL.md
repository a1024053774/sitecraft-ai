像一家对车间有信心的工厂，让已授权照片和大字说话。大胆不对称、整宽照片、尺度对比；照片依对应内容有主次裁切，不能全部等大。默认版式变化 8/10、信息密度 4/10；按用户滑杆调整，参数仍清楚。深浅区块可交替，一个饱和且不刺眼的强调色。无图时用真实能力和参数组织版面，不假装实拍。全站无动效。

用户给什么资料就做什么网站；只在用户资料或要求中明确提出相应网站功能时才做。不默认增加询盘表单、报价入口、邮箱联系或联系页。已有联系方式可按资料展示，但不据单项邮箱硬套独立联系页；商业条件不等于询盘功能要求。资料少就做得少，用户补充后再丰富。风格只调整现有内容的排法，不补营销流程或页面。
