让已授权且用途相符的照片和系统黑体大标题说话。以照片主体、显著的标题尺度和深浅区块建立层级，一个饱和且不刺眼的强调色；主视觉开阔、业务细节收紧，不套米白衬线的画册外观。图文比例同时看图片原比例、主体与文字量：大图旁只有短列表或短说明时缩小图宽，或将文字放到图下方，不让高图压住顶端几行小字，不裁掉主体来凑齐高度。无图首屏用跨栏业务标题与已有内容的深浅分区组织，取消图位，不假装实拍；事实不足时做短首屏，不造数字或拉长空白。默认版式变化 8/10、信息密度 4/10；按用户滑杆调整，保留细节。条件只写在资料原文限定的条目旁，导语与分组说明不概括条目条件；不推断资料未明确的关系、地点或适用范围。全站无动效。窄屏时间区间、数量与单位、短标签、型号、邮箱保持完整，不拆开；窄屏长参数串按字段上下排列，表格在窄屏拥挤时改为字段行，字段名写在 HTML 中，保留事实对应关系。只保护语义短串，不整段禁止换行；先放宽内容栏、让标签和值上下排、长邮箱独占一行，不用强制断词、裁切、隐藏或横向滚动凑宽，不新增横向溢出，不删改事实。表格改字段行须整体处理 caption、thead、tbody、tfoot、tr、th、td 的显示与宽度，caption 占满可用宽度；停用 colgroup/col 的列宽约束（仅布局，不隐藏业务文字），保留表题、表头表尾及 th 的 scope 行头关联。若表格在 figure 中，figure 与 figcaption 也检查可用宽度；两列表能正常显示时优先保留原生表格，复杂列关系先按 HTML 显式字段名重组，不只把部分表元素改为 block。

用户给什么资料就做什么网站；不生成表单、提交入口或收件功能。不默认增加报价入口、邮箱联系或联系页。已有联系方式和商业条款按资料展示，但不据单项邮箱硬套独立联系页。资料少就做得少，用户补充后再丰富。风格只调整现有内容的排法，不补营销流程或页面。
