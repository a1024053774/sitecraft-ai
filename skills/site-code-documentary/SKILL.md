让已授权且用途相符的现场/实物照片和大号系统黑体标题担当视觉重心，通过深浅明暗强烈反差的整宽区块交替建立阅读节奏。页头：深浅高反差双层纪实页头（上层紧致全称与定位条，下层通栏章节导航带或右对齐重黑标尺），避免千篇一律的浅灰底单行细线顶栏。字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`，标题采用粗重字重（700–800）紧缩行距（1.15–1.25），数值配合 `ui-monospace, Consolas, monospace`。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（车间石墨）主底 #FFFFFF（正文 #181A1C / 次字 #4A4F55）、深浅分区 #1C2024（正文 #F5F6F8 / 次字 #C3C8CE）、次区底 #ECEEED（正文 #181A1C / 次字 #454A50）、强调 #0C4DA2（字 #FFFFFF）；变体 B（原纸炭黑）主底 #F5F3EE（正文 #1D1C19 / 次字 #4D4B44）、深浅分区 #23211E（正文 #F7F5F0 / 次字 #CCC8BE）、次区底 #E6E2D8（正文 #1D1C19 / 次字 #48463F）、强调 #14532D（字 #FFFFFF）；变体 C（钢青重装）主底 #F2F5F7（正文 #161E24 / 次字 #42505A）、深浅分区 #102330（正文 #F2F6F9 / 次字 #BCCCD6）、次区底 #E2E9EE（正文 #161E24 / 次字 #3E4B55）、强调 #9A3412（字 #FFFFFF）。首屏与图文重量：大字跨栏标题配完整主图，图文比例同时依据原图宽高比、主体与文字量调节；大图旁只有短列表或短说明时缩小图宽，或将文字放到图下方，不让高图压住顶端几行小字，不裁切主体凑高度。无图首屏用跨栏重黑体业务标题与已有内容的深浅分区组织，取消图位，不假装实拍；资料少时做短首屏收紧，不造数字或拉长空白。含列表圆点或编号的有底色区块严格使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁做成「白底左上 Kicker 眉题 + H1 + 短说明 + 单实心小按钮 + 1px 横线」的通用模板，也不要把深色块做成单调一致的一卡两栏。

只调整现有资料的视觉与排版组织，保留全部事实、单位、条件与否定；遵循核心规范和同一提交入口，不生成表单、提交入口或收件功能，不默认增加报价入口或联系页，资料少就做得少。
