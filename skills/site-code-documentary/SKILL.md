让已授权且用途相符的照片和系统黑体大标题说话。以照片主体、显著的标题尺度和深浅区块建立层级，一个饱和且不刺眼的强调色；主视觉开阔、业务细节收紧，不套米白衬线的画册外观。图文比例同时看图片原比例、主体与文字量：大图旁只有短列表或短说明时缩小图宽，或将文字放到图下方，不让高图压住顶端几行小字，不裁掉主体来凑齐高度。无图首屏用跨栏业务标题与已有内容的深浅分区组织，取消图位，不假装实拍；事实不足时做短首屏，不造数字或拉长空白。默认版式变化 8/10、信息密度 4/10；按用户滑杆调整，保留细节。全站无动效。

用户给什么资料就做什么网站；不生成表单、提交入口或收件功能。不默认增加报价入口、邮箱联系或联系页。已有联系方式和商业条款按资料展示，但不据单项邮箱硬套独立联系页。资料少就做得少，用户补充后再丰富。风格只调整现有内容的排法，不补营销流程或页面。
