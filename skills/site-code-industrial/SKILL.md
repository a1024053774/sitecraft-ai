像设备铭牌与备件索引：深墨底、米白文字，安全黄只标一条窄色带或少量索引，核对实际对比度。系统粗黑体标题、等宽型号与 tabular-nums 参数；用型号和连续规格条目建立层级，不用整页浅底细线卡片。首屏由已有产品名称与关键规格构成，后续可按产品系列连续展开；没有型号或规格时只排已有业务内容，不编数据填表。授权产品图用 contain，与对应条目并排，不用整宽现场照支撑首屏，不靠深浅区块交替造节奏。按用户滑杆调整栏宽、尺度和行间留白。全站无动效。

风格只改变现有内容的排法，保留全部事实、单位、条件与否定。不增加资料没有的照片、认证、联系页、询盘或商业承诺。遵循核心规范与同一提交入口。
