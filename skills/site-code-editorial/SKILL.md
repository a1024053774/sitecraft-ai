像翻阅专印出版的品牌画册：依靠系统宋体跨平台衬线大标题与黑体正文的材质对比、大幅跨栏版心、纸色分区与宽窄栏反差建立阅读节奏。页头：居中双层刊头或桌面左栏固定窄目录条（180–220px 左侧目录索引配右侧开阔画册主版面，768px 以下收拢为顶部两行刊头），彻底避开常规左右两端对齐 64px 细线顶栏。字体栈：标题与刊名采用 `"Noto Serif CJK SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", Georgia, serif`，正文与规格用 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。配色角色（已按 >=4.5:1 对比度核算，优先按本次提示的变体执行）：变体 A（冷象牙墨黑）主底 #FAF8F4（正文 #1E1C1A / 次字 #4E4944）、纸色分区 #EFECE4（正文 #1E1C1A / 次字 #48433E）、墨黑底 #221F1D（正文 #FAF8F4 / 次字 #D0C9C0）、强调 #1F4E5F（字 #FFFFFF）；变体 B（松烟青灰纸）主底 #F6F7F5（正文 #1B201E / 次字 #48514D）、纸色分区 #E8ECE8（正文 #1B201E / 次字 #424A46）、墨黑底 #1F2823（正文 #F6F7F5 / 次字 #C2CCC6）、强调 #3A4E7A（字 #FFFFFF）；变体 C（暖砂赭墨）主底 #F7F2EA（正文 #241D18 / 次字 #55483E）、纸色分区 #EDE3D4（正文 #241D18 / 次字 #4D4138）、墨黑底 #2E221A（正文 #F8F3EB / 次字 #D4C7B9）、强调 #7C2D12（字 #FFFFFF）。首屏与节奏：大字号系统宋体跨栏主标题、宽版纸色分区与不对称窄栏导读构成首屏，避免逐节靠 1px 灰线切分页面；授权图片保留完整比例穿插正文，图旁说明贴近对应内容，不留与短说明等高的空栏；无图首屏用跨栏业务标题与紧接的真实业务入口构图，不只把短文缩在左边；资料少时收紧为短开篇，不造插画或补事实。含列表圆点或编号的有底色区块严格使用 `border-radius:0`、`background-clip:border-box`、outside 标记与 `z-index:auto`。反雷同禁令：严禁做成「白底左上 Kicker + 左对齐小按钮 + 下接二比一双栏 + 1px 横线」的通用模板。

首页先让访客看懂提供什么、如何了解：用资料中的产品或主要业务作开场重点，产品分类或主要业务入口必须在首屏或紧随其后，1440px 与 375px 都在首个滚动内可见。资料有不同业务路径时，在入口区分，并指向已有细节、适用限制或所需资料；没有就不补流程。入口随实际内容分组，不凑固定数量的卡片；仅在已有页面或段落之间导航。交易条件、设施与流程放在入口之后，不能让公司介绍或现场大图把入口挤到后面。

风格只改变现有内容的排法，保留全部事实、单位、条件与否定。不生成表单、提交入口或收件功能，不增加资料没有的照片、认证、联系页或商业承诺。遵循核心规范与同一提交入口。

来源：本项目原创风格；方法来源与许可见 [SOURCE.md](SOURCE.md)。T-153 独立盲评判为与现场实拍不同的方向；T-155 将产品或业务入口提前；T-227 改写为居中双层刊头／左栏目录与多变体纸色配方并迁出共用合同。
