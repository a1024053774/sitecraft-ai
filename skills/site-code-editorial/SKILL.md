像翻阅这家机构的品牌画册：暖白纸色、墨棕文字，用系统宋体（Songti SC、SimSun、serif）标题与系统黑体正文拉开层次，一处陶土色作强调。跨栏主标题、放大的主要业务名称与窄栏说明形成字阶和栏宽对比，纸色分区承载重点内容，连续阅读段保持开敞，不逐节靠细线和等距留白分隔。授权图片保留完整比例、穿插正文，图旁说明贴近对应内容，不留与短说明等高的空栏，不做整宽现场照片墙。无图首屏用跨栏业务标题与紧接的真实业务入口构图，不只把短文缩在左边；内容少时收紧为短开篇，不造插画或补事实。已有参数保持清楚的表格或列表；按用户滑杆调整对齐与疏密，保留画册节奏。条件只写在资料原文限定的条目旁，导语与分组说明不概括条目条件；不推断资料未明确的关系、地点或适用范围。全站无动效。窄屏时间区间、数量与单位、短标签、型号、邮箱保持完整，不拆开；窄屏长参数串按字段上下排列，表格在窄屏拥挤时改为字段行，字段名写在 HTML 中，保留事实对应关系。只保护语义短串，不整段禁止换行；先放宽内容栏、让标签和值上下排、长邮箱独占一行，不用强制断词、裁切、隐藏或横向滚动凑宽，不新增横向溢出，不删改事实。

首页先让访客看懂提供什么、如何了解：用资料中的产品或主要业务作开场重点，产品分类或主要业务入口必须在首屏或紧随其后，1440px 与 375px 都在首个滚动内可见。资料有不同业务路径时，在入口区分，并指向已有细节、适用限制或所需资料；没有就不补流程。入口随实际内容分组，不凑固定数量的卡片；仅在已有页面或段落之间导航。交易条件、设施与流程放在入口之后，不能让公司介绍或现场大图把入口挤到后面。

风格只改变现有内容的排法，保留全部事实、单位、条件与否定。不增加资料没有的照片、认证、联系页或商业承诺。遵循核心规范与同一提交入口。

来源：本项目原创风格；方法来源与许可见 [SOURCE.md](SOURCE.md)。T-153 独立盲评判为与现场实拍不同的方向，但「更像这家公司」选原版：原版采购路径直接，画册产品入口靠后。T-155 将产品或业务入口提前，保留画册气质；本次调整的真实生成与成对盲评待与 T-154 合跑。
