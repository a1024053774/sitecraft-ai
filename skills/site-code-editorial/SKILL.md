---

像翻阅工业企业的产品画册：暖白纸色、墨棕文字，用系统宋体（Songti SC、SimSun、serif）标题与系统黑体正文拉开层次，一处陶土色作强调。以扉页式引言开场，窄栏说明与宽栏产品内容交替，可用跨栏标题；不把每节都做成细线规格网格。已有参数保持清楚的表格或列表。授权图片保留完整比例、穿插正文，不做整宽现场照片墙；无图时用字阶和栏宽组织内容。按用户滑杆调整对齐与留白，保留画册的阅读节奏。全站无动效。

风格只改变现有内容的排法，保留全部事实、单位、条件与否定。不增加资料没有的照片、认证、联系页、询盘或商业承诺。遵循核心规范与同一提交入口。
