# SiteCraft AI 执行计划

状态：v0.14（2026-09-24），「下一步」经负责人 grilling 确认。需求以 [intent.md](./intent.md) 为准，主线以 [mainline.md](./mainline.md) 为准。已完成的轮次和「系统功能收口 1–5」已移到 [plan-history.md](./plan-history.md)，只供追溯。

## 要做成什么样

帮中小企业做出看起来像该行业自己建的网站：好看、不像套模板或套 AI 文案、事实不编造、改完能立刻在预览里看到。近期是**内部 Demo**，负责人扮演用户，资料用模拟工业/设备/外贸包。

判断一项工作值不值得做，只问一句：**它有没有让负责人看到的生成站更好看、更真、更好改？** 没有就不是当前工作。

## 现在到了哪里（2026-09-24）

能用的：

- 主链：资料/Prompt → 可选需求对齐（模型动态提问、点选、刷新可恢复）→ 方案确认 → `commitOperations` 写草稿 → 共享 `preview-bridge` 预览 → 对话修改/撤销 → 发布页同一草稿。
- 四个视觉族有 SiteCraft 自己的首页 overlay（`forge` 明亮产品、`screwfast` 工程工业、`landwind` 蓝白目录、`tailwind-landing` 灰底短路径），各 4 套命名色板，换色不动版式和内容。
- 系统功能收口 1–5 已提交（`ee10225`..`6295956`，未推送）：预览失败态与重试、quality 失败格、子页不克隆首页、撤下 fresh、发布页不显示开发提示。验收结论和缺陷见 [review-2026-09-24.md](./review-2026-09-24.md)。
- `npm test` 204/204、`typecheck`、`build` 通过。

还不行的（按对成品的影响排序）：

1. **overlay 里写死的文字**：四个视觉族都有写给负责人看的方法论句子、固定中文导航/表单标签，`screwfast` 还写死了 P3I 的事实。换公司、换语言都不变。
2. **英文站是默认文案**：生成只写中文，EN 显示与公司无关的通用句。
3. **负责人还没重新盲评**。2026-09-18 P4 盲评不过之后，所有“通过”都是代理或外部模型自评。
4. 预览在 Claude 桌面端内置浏览器里被拦（沙箱 iframe），负责人已决定查看和盲评都用 Chrome。
5. 子页 overlay、`fresh` kit、其余 18 套模板仍未做，属正常延后。
