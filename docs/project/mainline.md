## 要做成什么样

内部 Demo：用模拟的任何行业中小企业与机构资料，做出看起来像那家企业自己建的展示型官网（T-156；核心规范、风格与评估集的通用化见 T-157–T-159）。行业对得上、版式有差异、事实不编、预览里改完能看见、对话可以停下来再继续。

公开上线、真实客户试点、整仓合并 PR #4，都不是本阶段。

数据删除按 2026-09-18 用户决定（取代 Q17=A）：删除须由用户明确选择；系统不得替用户主动删除对话、草稿、上传或站点。不实现 90 天自动清理，也不保留可暂停的自动清理开关。已发布站点仍由用户控制，不得静默删除。

标准测试每轮使用独立、经 health 核对的数据根；测试存储未取得本轮许可时在读写前拒绝，不回退用户的默认目录。测试服务用独立 `.next-test` 与随机端口，可与同目录普通 dev 共存。入口须实际执行用例，零用例不得报通过；命令与回归证据见 AGENTS 和 T-167。各 store 保留可静态分析的路径，测试守卫只做许可核验，运行时身份路径不作为部署追踪输入。普通开发的数据合同不变，既有测试站是否删除仍由负责人决定。

## 素材怎么用

图片、字体、图标、商标分别核许可，代码 MIT/Apache 不批准其余素材。图片经用户上传与许可登记进入站点，模型只引用编号，署名由系统汇总。没有授权照片时用无图版，不冒充本机构实拍。vendor 模板库与运行、构建入口已移除；研究记录不能作为运行时准入。

系统抽象底图由 MIT 的 shaders@4.0.4 开源组件离线渲染；主控保留细线网格、疏点阵、单向色场、偏心色场、微纸纹、细颗粒六类，精密／纪实各两组配色，三档共 72 张。来源与排除理由见 `resources/shader-backdrops/SOURCE.md`；登记表为 `lib/code-site-backdrops.ts`，静态文件在 `public/system-backdrops/`。运行时不加载 shader 或渲染；预览与发布共用静态渲染器解析容器标记、选择宽度并汇总署名与许可。所有代码仍经唯一提交入口检查登记地址、背景用途、实际加载及实际解码色域与 CSS 叠层的保守对比度，不依据配色元数据放行。

参考站只供理解内容组织、空间和全站一致性，不搬运对方代码、文案或未授权素材。先用核心规范与用户选择的风格建立统一视觉关系，再按这家公司的资料写页面。研究材料不自动加载为 Skill。
